Setup

  1. Create an application at discord.com/developers/applications and add a bot.
  2. On the Bot tab, turn on Server Members Intent and copy the token into the card on the left.
  3. Invite the bot with OAuth2, URL Generator: scope bot, permissions View Channels, Send Messages, Embed Links, Add Reactions, Read Message History.
  4. Pick the server, then enable this module.
