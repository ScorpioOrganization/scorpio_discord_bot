How it works

  • ClickUp's API does not show recurrence settings, so each rule here maps a ClickUp tag to an interval. Tag a task to make it recur, remove the tag to stop it.
  • When done: a tagged task in a done or closed status recurs. When due: it recurs once its due date passes, whatever its status.
  • The next due date is the first one after now, a whole number of intervals after the old one, so missed occurrences are skipped and a task done early keeps its rhythm. The start date moves by the same amount.
  • Move task changes the task's dates and status. Copy task leaves it and creates a copy (name, description, tags, assignees, priority; not checklists, subtasks, custom fields or attachments), only for tasks due in the last 60 days.
  • Remove ClickUp's own recurrence from tagged tasks, or a task can be moved twice.
  • At most {{ max_writes }} tasks change per run, every occurrence only once. Scheduled runs need the bot online; Run now always works.
